## Abstract

LifeBridge Smart Organ Transplant System is a service-oriented healthcare platform designed to manage and coordinate organ donation and transplantation activities. It supports donor registration, recipient management, organ availability, compatibility assessment, matching and allocation, and notifications.

The system follows a microservices-based SOA architecture with independent services for user authentication, donor management, recipient management, organ management, matching and allocation, and notifications. It uses REST APIs, JWT authentication, role-based authorization, Eureka Service Discovery, Spring Cloud Gateway, and a database-per-service approach.

## Objectives

- Manage donor and recipient information.
- Maintain organ availability.
- Support compatibility assessment and matching.
- Improve organ allocation and coordination.
- Provide secure access to authorized users.
- Provide timely notifications.
